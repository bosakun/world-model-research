# 世界モデルを物理世界へつなぐ前に必要なこと

## 1. pixelを全部復元しなくてもよいのか

JEPA系の考え方では、次の画像の全pixelを描き直す代わりに、actionの後で予測できる重要な表現だけを予測します。

    現在の表現 + action -> 未来の表現

これは、背景の細かな模様を当てるより、物体がどこへ動くかのような制御に必要な変化へ集中したい、という考え方です。

ただし、どの情報を捨てても安全かは自動では決まりません。taskに必要な情報が表現から消えていないかを評価する必要があります。

## 2. robot interfaceは安全装置である

学習modelは、望ましくないactionや範囲外の数値を出すことがあります。その出力をモーターへ直接送ってはいけません。

    modelのaction要求
    -> 範囲チェック
    -> 速度・力・位置の制限
    -> 非常停止の確認
    -> robotへ実行
    -> 観測・action・結果を記録

この境界は単なる配線ではなく、安全と再現性を守る重要な部品です。

## 3. sim-to-real

simulationで正しく動いても、実機では摩擦、遅延、センサー誤差、壊れやすさが違います。world modelを物理世界へ持ち出すには、モデルの予測誤差を前提にした再計画、制限、監視が必要です。

## 4. まとめ

- 表現予測は、全pixel復元と異なる世界モデルの選択肢である。
- 実機へのactionは安全なinterfaceを必ず通す。
- 物理世界では、予測が外れることを前提に設計する。
