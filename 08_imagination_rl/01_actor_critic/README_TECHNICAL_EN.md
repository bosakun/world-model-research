# Actor–Critic Learning from Latent Imagination

Status: completed on 2026-08-22. Simplified educational Dreamer-style mechanism study, not a Dreamer/DreamerV2/DreamerV3 reproduction.

## Purpose

Train an actor and critic using trajectories generated entirely inside a learned latent world model, then audit the deterministic actor in the exact environment.

## Problem

CEM repeatedly optimizes action sequences online. An actor can amortize that search into a direct action mapping, while a critic estimates longer-term consequences. But training them on imagined data makes behavior quality depend on world-model accuracy.

## Previous Model

`07_planning/04_latent_planning` learned encoder, latent transition, reward, and value functions and optimized each plan with CEM. It did not learn a reusable policy.

## Hypothesis

A differentiable stochastic actor trained through the frozen latent transition and reward model, with a λ-return critic, should learn a policy that reduces true Goal distance without receiving real-environment policy gradients. It may exploit model errors and fail exact success.

## Architecture

```text
real start observation (sampling only)
        |
 frozen encoder -> z_0
        |
 Gaussian actor --rsample+tanh--> a_t
        |                            |
        +<-- frozen latent transition/reward --> z_(t+1), r_hat_t
                                             |
                                      target critic V_bar
                                             |
                                          lambda-return
                                         /             \
                           dynamics-gradient actor    critic regression
```

The behavior optimizer never steps the exact environment. Exact dynamics are used only after training for evaluation.

## Data Flow

Each update samples 256 random agent/Goal pairs and encodes them. Twelve differentiable imagined steps generate actions, rewards, and latents. The frozen target critic bootstraps λ-returns. Actor parameters receive gradients through sampled actions, frozen dynamics, frozen reward, and target-critic input gradients. The critic fits detached λ-return targets, then its target copy receives an EMA update.

## Tensor Shapes

| Quantity | Shape |
|---|---|
| start observations | `[256,4]` |
| initial latent | `[256,16]` |
| imagined latents | `[256,13,16]` |
| imagined actions | `[256,12,2]` |
| rewards / entropies | `[256,12]` |
| next critic values | `[256,12]` |
| λ-return targets | `[256,12]` |

## Mathematics

The actor samples differentiably:

```text
u_t = mu_phi(z_t) + sigma_phi(z_t) epsilon, epsilon~N(0,I)
a_t = tanh(u_t).
```

The backward λ-return is

```text
G_t^lambda = r_hat_t + gamma[(1-lambda)V_bar(z_(t+1)) + lambda G_(t+1)^lambda].
```

The actor and critic objectives are

```text
L_actor  = -mean(G_t^lambda) - eta mean(H[pi(.|z_t)])
L_critic = mean(V_psi(z_t) - sg(G_t^lambda))^2.
```

`V_bar` is an exponential-moving-average target critic, and `sg` stops target gradients in critic regression. World-model parameters are frozen, but differentiability through its operations lets the actor see how actions alter predicted returns.

## Training

- prerequisite: Phase 07 latent-model checkpoint generated by its `train.py`;
- seed 131, 500 behavior updates, batch 256, imagination horizon 12;
- actor Adam `3e-4`; critic Adam `5e-4`;
- `gamma=0.97`, `lambda=0.95`, entropy weight `1e-3`, target EMA `0.98`;
- world/actor/critic parameter counts: 5,922 / 5,508 / 5,313;
- combined checkpoint format version 1 includes frozen world, actor, critic, target critic, config, and update count.

Run:

```bash
MPLCONFIGDIR=/tmp/world-model-mpl .venv/bin/python 08_imagination_rl/01_actor_critic/train.py
MPLCONFIGDIR=/tmp/world-model-mpl .venv/bin/python 08_imagination_rl/01_actor_critic/evaluate.py
```

## Losses

- actor loss improves predicted λ-return via pathwise/dynamics gradients and preserves a small amount of exploration through entropy;
- critic loss approximates imagined returns for bootstrapping;
- target EMA slows the moving-target feedback loop;
- the world model receives no gradient and no further real data in this phase.

## Evaluation Interface

`evaluate.py` loads the combined checkpoint, uses the actor mean action, re-encodes the exact observation after each environment step, and reports success, distance, exact reward, and the prohibition on real-environment behavior training.

## Smoke Test Results

Four focused tests passed. Imagined reward mean improved from `-0.6664` to `-0.1922`, while mean imagined λ-return rose from `-3.1524` to `+5.1975`. In the exact environment, distance fell from `2.2672` to `0.5128` (77.4%), but the actor did **not** reach the `0.08` success radius in 20 steps. The critic became optimistic and the path drifted to the upper boundary rather than the Goal.

## Failure Cases

- Model exploitation: imagined return became strongly positive while exact total reward was `-16.18` and success was false.
- Critic extrapolation: predicted value changed from roughly `-14` to positive values, inconsistent with exact Goal distance.
- Actor saturation: deterministic actions led toward a boundary region favored by model errors.
- Fixed continuation imagines through all 12 steps; no learned termination protects return targets.
- A weak reward model is amplified by actor optimization.

## Findings

The complete imagination-to-actor-gradient-to-exact-evaluation path works. The failure is scientifically more informative than declaring control solved: actor optimization finds errors that a finite CEM smoke test only partly exposed. Better world-model validation, continuation, uncertainty, and real-data refresh are prerequisites for trustworthy imagination learning.

## Limitations

This uses deterministic continuous latent states and a simple Gaussian actor. It omits RSSM posterior-start sampling, learned continuation, replay collection, slow value regularization beyond EMA, return transformations, discrete latents, distributional critics, robustness tricks, and environment interaction loops found across Dreamer generations.

## Dreamer Family Relationship

- Dreamer (2019): continuous RSSM imagination and actor/value learning established the main conceptual path used here.
- DreamerV2 (2020): moved to categorical discrete latent states and introduced behavior-learning refinements for Atari; those mechanisms are not implemented here.
- DreamerV3 (2023): emphasized one robust configuration across domains using normalization, transformations, balancing, and other stability choices; those mechanisms are not implemented here.

This folder implements only differentiable latent imagination, λ-return actor/critic learning, entropy regularization, and a slow target critic on the Phase 07 deterministic model.

## Final Model Candidate

```text
Candidate: Undecided
Reason: Amortized imagined behavior learning works mechanically, but the learned policy exploits model/critic error and misses the Goal.
Advantages: direct low-latency action; no real policy-gradient trajectories; differentiable long-horizon objective.
Disadvantages: severe model exploitation; coupled actor/critic instability; sensitive bootstrapping.
Possible conflicts: conservative uncertainty penalties may oppose optimistic actor gradients; stochastic RSSM state changes return variance.
```
