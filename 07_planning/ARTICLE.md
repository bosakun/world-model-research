# 世界モデルで未来を想像して行動を選ぶ

## 1. Planningとは何か

Planningは、実際にactionする前に、world modelの中で未来を試すことです。

    候補A: 右、右、上
    候補B: 上、右、右
    -> 未来のrewardを予測
    -> 良い候補の最初のactionを実行

本物の環境で全部試す必要がない点がworld modelの利点です。

## 2. Random Shooting

random shootingは、action列をランダムにたくさん作り、最も高い予測scoreの列を選びます。

分かりやすく、最初の基準になります。しかしactionの種類や計画時間が長いと、良い列を偶然引く確率が下がります。

## 3. CEM

CEMはCross-Entropy Methodの略です。最初は広く候補をsampleし、高得点だった候補だけを残します。その候補の近くを次に多くsampleします。

    広く試す
    -> 良い候補を選ぶ
    -> 良い候補の周辺を重点的に試す

これは「良さそうな場所を少しずつ絞る」探索です。世界モデルが間違っている場所では、間違った未来へ強く最適化する危険もあります。

## 4. MPC

長いaction列を一度決めて最後まで実行すると、予測誤差が積み重なります。MPCは、計画した列の最初のactionだけを実行し、次の観測を受け取ってから計画を作り直します。

    計画 -> 最初の一歩だけ実行 -> 観測 -> 再計画

この再計画が、モデルの予測誤差へのフィードバックになります。

## 5. latent planning

画像を毎step復元して採点すると重い場合があります。latent planningは、latent stateからrewardやvalueを予測して候補を採点します。

ただし、画像を復元しないからといって世界の細部を無視してよいわけではありません。controlに必要な情報がlatentに残っていなければ、計画は失敗します。

## 6. まとめ

- random shootingは最も単純な候補探索。
- CEMは良い候補の周りを集中的に探索する。
- MPCは観測のたびに計画を作り直す。
- latent planningは内部表現だけで未来を採点する。
- Planningの質は、world model、reward/value、探索方法のすべてに依存する。
