# C-SWMで物体ごとの世界を表す

## 何が困るのか

画像全体を一つのlatent vectorへ入れると、Agent、Goal、壁などの情報が混ざります。どの部分がどの物体かを扱いにくくなります。

## C-SWMの考え方

各物体らしいものに別のstateを持たせ、物体同士の関係から次のstateを予測します。

    object Aのstate + object Bのstate + 関係
    -> 次のobject state

## なぜ良いか

同じ物体の動きruleを複数の物体へ使いやすく、関係も明示しやすくなります。ただし、画像を正しく物体へ分けられるとは自動で保証されません。

## 自分で説明できるか

- 一つのlatent vectorでは何が混ざるか。
- C-SWMは何を物体ごとに持つか。
- 物体分割を間違えると何が困るか。
